# ملف تسليم ومتابعة — منظومة المتابعة

**آخر تحديث:** 14 نوفمبر 2026  
**حالة المشروع:** الدخول مربوط بنظام مستخدمين فعلي؛ اللوحة بدون بيانات بعد

## ملخص المشروع

تطبيق ويب عربي باسم **منظومة المتابعة**، بهوية بصرية رسمية تعتمد الكحلي البترولي والذهبي، مع شعار متحرك وواجهة دخول متجاوبة.

## تعريف العمل المعتمد

المنظومة مخصّصة لفرع الطرق في **كتيبة 91 طرق** لمتابعة مشروعات الطرق المدنية. التصور المبدئي: نحو 50 مشروعًا، وكل مشروع قد يرتبط بما يصل إلى 100 شركة منفذة أو مورّد/مقاول. المطلوب الأساسي هو جمع ومراجعة المواقف التنفيذية، قياس التقدم، وتقديم رؤية موحدة للإدارة.

لا تُدرج أي بيانات عسكرية تشغيلية أو بيانات أشخاص حساسة داخل النظام؛ يقتصر نطاقه على بيانات مشروعات الطرق والمتابعة المدنية.

## معيار التصميم المعتمد

الهدف هو نظام مؤسسي تشغيلي، وليس واجهة عرض أو نموذجًا دعائيًا. لذلك تعتمد الشاشات القادمة على:

- لغة عربية مباشرة مرتبطة بالعمل، دون عبارات تسويقية عامة.
- بيانات فعلية فقط عند تزويدها؛ قبل ذلك نستخدم حالات فارغة واضحة بدل أسماء أو أرقام مختلقة.
- أيقونات واجهة متسقة بصيغة SVG، وليس رموز Emoji أو زخارف غير وظيفية.
- ألوان هادئة وتباين واضح، مع تقليل التدرجات والحركات إلى ما يخدم الاستخدام.
- جداول، حالات، فلاتر، وإجراءات واضحة تناسب العمل اليومي على المشاريع والمستخلصات.

## ما تم إنجازه

- تحسين الشعار وتحويله إلى أصل PNG بخلفية شفافة.
- اعتماد الألوان:
  - كحلي بترولي: `#08263D`
  - ذهبي: `#D4A72C`
  - أبيض دافئ: `#F8F5EE`
  - أحمر للحالات المهمة: `#D62828`
- إنشاء واجهة دخول عربية تتضمن اسم المستخدم، كلمة المرور، خيار التذكر، ورابط استعادة كلمة المرور.
- إنشاء لوحة متابعة أولية بعد تسجيل الدخول، تضم قائمة جانبية وملخصات المشروعات والشركات والمستخلصات والمواقف التنفيذية.
- إضافة حركة حية للشعار: ارتفاع وانخفاض هادئ، حلقة ضوء، ولمعة دورية.
- دعم شاشات الجوال والحركة المخففة لمن يفضّلونها.
- قاعدة التصميم الثابتة: الواجهة متجاوبة من البداية مع الشاشات الكبيرة، الأجهزة اللوحية، الهواتف، iPhone وAndroid؛ على الهاتف تتحول القائمة الجانبية إلى شريط تنقل مختصر وتُرتّب البطاقات تلقائيًا.
- اختبار تشغيل الصفحة واللوجو محليًا بنجاح (HTTP 200).
- تحسين قابلية قراءة النص في مساحة الشعار: بطاقة داكنة شبه شفافة للنص، أبيض عالي التباين، وشارة حالة أوضح.

## محتويات المجلد

> **مكانه في المستودع:** مجلد `monazoma/` داخل مستودع `eldamam-mostakhlasat`، منفصل تمامًا عن برنامج مستخلصات الدمام (`site/` و`src/`)؛ لا يُنشر تلقائيًا مع Netlify أو GitHub Pages.

- `monazoma/` — مصدر الموقع الجاهز للتشغيل (كان اسمه `الموقع/` في النسخ المضغوطة).
  - `dist/index.html` — واجهة الدخول.
  - `dist/dashboard.html` — لوحة المتابعة الأولية بعد الدخول.
  - `dist/assets/logo.png` — نسخة الشعار المستخدمة في الواجهة.
  - `تشغيل-السيرفر-المحلي.bat` — شغّله بالنقر المزدوج، ثم افتح `http://127.0.0.1:4173`.
- `الأصول/logo-web-refined.png` — الشعار المحسّن بخلفية شفافة.
- `منظومة-المتابعة-واجهة-الدخول-v1.zip` — نسخة مضغوطة قابلة للمشاركة.
- `منظومة-المتابعة-واجهة-الدخول-v2-تباين-محسن.zip` — النسخة الأحدث بعد رفع وضوح النص.
- `منظومة-المتابعة-لوحة-المتابعة-v3.zip` — نسخة تضم واجهة الدخول ولوحة المتابعة الأولية.

## نظام المستخدمين (Supabase)

- مشروع Supabase منفصل باسم `monazoma` (المنطقة: فرانكفورت `eu-central-1`، الخطة المجانية) — مستقل عن مشروع مستخلصات الدمام.
- الربط في `monazoma/dist/assets/auth.js` (الرابط والمفتاح العام فقط؛ المفتاح العام آمن في الواجهة لأن الحماية بقواعد RLS).
- جدول `profiles` لكل مستخدم: الاسم، الصلاحية (`admin` مدير · `editor` إدخال وتعديل · `viewer` اطلاع فقط)، ونشط/موقوف. الملف: `monazoma/supabase/migrations/0001_profiles.sql`.
- أي حساب جديد يأخذ صلاحية «اطلاع فقط» تلقائيًا، والمدير وحده يغيّر الصلاحيات أو يوقف الحسابات. تم التحقق: المستخدم العادي لا يستطيع رفع صلاحيته، والزائر بدون دخول لا يرى أي بيانات.
- **اسم المستخدم:** يُكتب بدون @ ويتحول داخليًا إلى `<الاسم>@monazoma.local`. مثال: الحساب `ahmed@monazoma.local` يدخل باسم `ahmed`.
- «تذكرني» يحفظ الجلسة على الجهاز؛ بدونه تنتهي الجلسة بقفل المتصفح.
- «نسيت كلمة المرور» يوجّه للتواصل مع المدير (الحسابات بدون بريد حقيقي).
- مستخدم «اطلاع فقط» لا يرى زر «إضافة موقف تنفيذي».

### إنشاء أول حساب مدير (مرة واحدة)

1. لوحة Supabase ← مشروع `monazoma` ← **Authentication ← Users ← Add user ← Create new user**.
2. البريد: `<اسم المستخدم>@monazoma.local`، وكلمة مرور قوية، مع تفعيل **Auto Confirm User**.
3. **SQL Editor** وتشغيل:
   ```sql
   update public.profiles set role = 'admin', name = 'الاسم الظاهر'
   where id = (select id from auth.users where email = '<اسم المستخدم>@monazoma.local');
   ```
4. يُستحسن من **Authentication ← Sign In / Providers** إيقاف **Allow new users to sign up** حتى لا يُنشئ أحد حسابًا لنفسه (حتى لو حصل سيكون «اطلاع فقط»).
