# برومبت جاهز لحساب Claude جديد

> **إزاي تستخدمه:**
> 1. على حساب Claude الجديد افتح Claude Code (على الويب claude.ai/code، أو على جهازك).
> 2. اربطه بمستودع GitHub `khalidjomaa98-collab/eldamam-mostakhlasat`، أو ارفع فولدر المشروع كامل ومعاه `docs/handover/`.
> 3. لو هتشتغل من Claude.ai Projects: ارفع ملفات `docs/handover/*.md` + `src/shim.js` + `src/build.py` + `src/sw.js`، وارفع `src/app.html` لو حجم الملف مسموح.
> 4. لو عايزه يدير قاعدة البيانات مباشرة: اربط Supabase connector **بحساب Supabase المالك لمشروع `mostakhlasat`**، مش أي حساب تاني.
> 5. انسخ النص اللي تحت كما هو.
>
> **متلصقش في المحادثة أي كلمة سر أو مفتاح سري.** لو احتاج حاجة زي دي، أدخلها انت بنفسك في لوحة التحكم.
